# Translation status

- The interface provides English, Hindi, Marathi and Gujarati language switching throughout the assessment.
- Existing source translations from the master questionnaire were mapped to matching coded questions where identifiable.
- Core demographic fields, shared symptom questions and key navigation/safety text have translated labels.
- Some newer authored reproductive, family-history, exposure and pediatric questions/options still use English fallback. Options are translated only where a known response mapping exists.
- No language version is clinically approved. Qualified medical translators and clinicians fluent in each language must review question meaning, reading level, cultural interpretation, anatomical terminology and urgent-care instructions before patient-facing use.
